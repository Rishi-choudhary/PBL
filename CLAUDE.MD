# Project rules
Third-year B.Tech project: crop and fertilizer recommendation research paper (IEEE format) and PPT.
- Never invent a number, citation, dataset, or result. If something is missing, write "NOT AVAILABLE" and say why.
- Every number in the paper must come from a file in results/. Keep results/CLAIMS.md as the ledger: claim -> file -> value.
- Every citation must be verified (DOI or URL opened and checked). Unverifiable references are removed, not guessed.
- The Kaggle crop dataset and the 99-row fertilizer dataset are leaky benchmarks. Never present their accuracy as agronomic evidence.
- Do not call experiments done if they were not run on real data.
- Ask me before adding scope I did not request.
- Writing: first person plural ("we"), plain precise sentences, no filler, no inflated vocabulary. Do not pad.
